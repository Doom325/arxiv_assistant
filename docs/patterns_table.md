| SSM | `structured_state_space_duality` | Selective SSMs and linear attention are mathematically equivalent — both compute structured semiseparable matrix multiplications — enabling a single model to switch between a recurrence view (O(1) inference) and an attention view (parallelizable training) via chunkwise decomposition. | Transformers are SSMs / Mamba-2: State Space Duality (arXiv:2405.21060) |
| SSM | `hybrid_recurrence_attention_interleaving` | SSM layers and sparse attention layers are interleaved at a fixed or learned ratio; SSM layers handle linear-time token mixing while attention layers provide periodic full-recall cross-token comparison, with optional MoE co-location. | Jamba: Hybrid Transformer-Mamba Language Model (arXiv:2403.19887); Samba: Simple Hybrid SSMs with Sliding Window Attention (arXiv:2406.07522) |
| SSM | `linear_complexity_long_context_scaling` | Replacing attention with recurrent SSM layers achieves O(n) training complexity and O(1) per-token inference state regardless of sequence length, enabling 256K+ token context windows without KV-cache memory growth. | SSM vs. Hybrid Long Context Benchmark (arXiv:2507.12442) |
| SSM | `dynamic_compute_allocation_routing` | MoE gating combined with SSM layers routes each token to a small expert subset, decoupling model capacity (total parameters) from inference compute (active parameters), enabling large-capacity models at practical throughput. | Jamba: Transformer-Mamba-MoE Hybrid (arXiv:2403.19887) |
| SSM ✦ | `hardware_aware_state_parallelism` | SSM recurrence is reformulated as a parallel associative scan over block-diagonal or semiseparable matrices that maps onto GPU/TPU SRAM hierarchies, fusing intermediate activations in on-chip memory to eliminate HBM bandwidth bottlenecks. | Mamba-2 / State Space Duality with hardware-aware parallel scan (arXiv:2405.21060); FlashLinearAttention: IO-Aware Linear Attention (arXiv:2409.17366) |
| World Models | `latent_space_predictive_coding` | Model predicts abstract representations in a learned embedding space rather than reconstructing raw pixels; a context encoder produces observed embeddings and a predictor forecasts future embeddings for masked spatio-temporal regions with no decoder. | V-JEPA 2: Action-Conditioned World Model (arXiv:2506.09985); Sora Latent World Model Analysis (arXiv:2407.10311) |
| World Models | `action_conditioned_latent_rollout` | A Recurrent State-Space Model maintains both a deterministic pathway and a stochastic latent variable; given a current latent state and proposed action, the model rolls forward imagined future trajectories entirely in latent space for policy planning. | DreamerV3: Mastering Diverse Domains Through World Models (arXiv:2301.04104); DREAMer-VXS: Latent World Model for AGV Exploration (arXiv:2512.00005) |
| World Models | `cross_modal_grounded_simulation` | A multimodal encoder fuses visual, linguistic, and proprioceptive signals into a shared latent world state; an LLM/VLM reasoning core decomposes tasks while a diffusion-based action decoder converts latent plans into motor commands. | Embodied AI: From LLMs to World Models (arXiv:2509.20021); Survey of Embodied World Models (arXiv preprint, 2024) |
| World Models ✦ | `hierarchical_temporal_abstraction` | World model is structured into multiple discrete time scales operating concurrently — high-level modules predict distant future waypoints while low-level modules generate fine-grained transitions — decoupling macro-goal planning from micro-action execution. | Genie: Generative Interactive Environments (arXiv:2402.15391) |
| Cross-Domain | `ssm_as_recurrent_world_state_backbone` | SSM layers replace attention inside world model temporal encoders, maintaining a fixed-size continuously updated latent world state; the SSM's hidden state becomes the RSSM's deterministic pathway, reducing O(n²) attention-over-history to O(n). | On Memory: Comparison of Memory Mechanisms in World Models (arXiv:2512.06983) |
| Cross-Domain | `offline_imagination_agent_training` | Agent policy is trained entirely within a world model's latent simulation from offline demonstration data; at deployment only the compact policy executes in real time, eliminating the cost and safety risk of online environment interaction. | DreamerV3 (arXiv:2301.04104); DREAMer-VXS: Latent AGV Exploration from Offline Data (arXiv:2512.00005) |
